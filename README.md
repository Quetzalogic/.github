# Estándares de contribución de Quetzalogic

Este repositorio público contiene archivos comunitarios predeterminados para los repositorios de la organización que no definan los suyos.

Su contenido es deliberadamente genérico y no debe incluir datos personales, credenciales, nombres de clientes, detalles de infraestructura ni información interna. Un repositorio puede reemplazar cualquiera de estos archivos con una versión propia.
