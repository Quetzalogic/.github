# Política de seguridad

## Reportar una vulnerabilidad

No abras un issue, discusión ni pull request público con información de una vulnerabilidad.

En un repositorio público que tenga habilitado el reporte privado de GitHub, abre la pestaña **Security**, entra a **Advisories** y selecciona **Report a vulnerability**. Incluye el impacto, los pasos mínimos para reproducir el problema y una prueba de concepto sin datos reales.

Para un repositorio privado, o si la opción no está disponible, comunica los detalles a un administrador mediante un canal privado ya establecido y verificado. No publiques la información en un issue. El reporte privado de vulnerabilidades de GitHub está pensado para repositorios públicos.

Da tiempo razonable para confirmar, investigar y corregir el hallazgo antes de cualquier divulgación coordinada.
