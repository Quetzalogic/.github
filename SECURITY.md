# Política de seguridad

## Reportar una vulnerabilidad

No abras un issue, discusión ni pull request público con información de una vulnerabilidad.

Usa exclusivamente el reporte privado de vulnerabilidades de GitHub del repositorio afectado: abre la pestaña **Security**, entra a **Advisories** y selecciona **Report a vulnerability**. Incluye el impacto, los pasos mínimos para reproducir el problema y una prueba de concepto sin datos reales.

Si esa opción no está habilitada, no publiques los detalles. Solicita a un administrador del repositorio, mediante un canal privado ya establecido y verificado, que habilite el reporte privado. Este documento no define ni inventa direcciones de correo o contactos alternativos.

Da tiempo razonable para confirmar, investigar y corregir el hallazgo antes de cualquier divulgación coordinada.
